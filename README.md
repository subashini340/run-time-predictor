# 🏃‍♂️ Marathon Finish Time Predictor AI

Intha project, oru Marathon runner-oda early race stats (like 5K split time, pace rate, age, and gender) use panni, avanga final finish time-ah predict panra oru AI/ML Web Application.

## ✨ Features
* **Machine Learning:** Random Forest Regressor use panni train pannirukkom.
* **Accuracy:** Model R² Score - 0.993 (Romba high accuracy).
* **Error Rate:** Mean Absolute Error (MAE) - 1.88 minutes (Just 2 minutes difference).
* **Web Interface:** Streamlit use panni user-friendly website create pannirukkom.

## 📊 Dataset
* **Source:** Kaggle (Boston Marathon 2015, 2016 & 2017 Results)
* **Total Data:** ~79,000 Runners.

## 🛠️ Tech Stack
* Python
* Pandas & Numpy (Data Processing)
* Scikit-Learn (Machine Learning)
* Streamlit (Web App)
* Joblib (Model Saving)

## 🚀 How to Run Locally
1. Install requirements: `pip install -r requirements.txt`
2. Run the web app: `streamlit run app.py`

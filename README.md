# 🏃‍♂️ Marathon Finish Time Predictor AI

This project is an AI/ML Web Application that predicts a marathon runner's final finish time based on their early race statistics (such as 5K split time, pace rate, age, and gender).

## ✨ Features
* **Machine Learning:** Trained using a Random Forest Regressor model.
* **High Accuracy:** Achieved an R² Score of 0.993.
* **Low Error Rate:** Mean Absolute Error (MAE) is just 1.88 minutes.
* **Web Interface:** Built a user-friendly and interactive website using Streamlit.

## 📊 Dataset
* **Source:** Kaggle (Boston Marathon 2015, 2016 & 2017 Results)
* **Total Data:** Approximately 79,000 runner records.

## 🛠️ Tech Stack
* **Python**
* **Pandas & NumPy** (Data Processing)
* **Scikit-Learn** (Machine Learning)
* **Streamlit** (Web Application)
* **Joblib** (Model Saving)
